# 🏏 IPL Web Design - Royal Challengers Bengaluru (RCB)

A dynamic, premium Single Page Application (SPA) designed to showcase the Royal Challengers Bengaluru (RCB) cricket team. This project features a sleek, modern UI, dynamic data rendering, and interactive components.

## ✨ Features
- **Premium UI/UX:** Dark mode aesthetics with gold accents, glassmorphism effects, and smooth micro-animations.
- **Dynamic SPA Routing:** Seamlessly navigate between Home, Squad, Stats, Fan Zone, and News sections without reloading the page.
- **Live Match Countdown:** Real-time countdown to the next big match.
- **Automated Image Sliders:** A beautiful carousel to browse the latest news and match highlights.
- **Interactive Data:**
  - Full player roster with real, high-quality headshots and detailed stats.
  - Interactive charts (using Chart.js) for team performance.
- **Fan Zone:** Features a fully functional Fan Poll and an animated team anthem section.

## 🛠️ Technologies Used
- **HTML5:** Semantic structuring for the app.
- **CSS3:** Custom properties, CSS Grid/Flexbox, dynamic gradients, and keyframe animations.
- **Vanilla JavaScript:** DOM manipulation, automated carousels, and SPA routing logic.
- **Chart.js:** For rendering interactive statistics.

## 🚀 How to Run
1. Clone the repository.
2. Open the `index.html` file in any modern web browser.
3. No build tools or local servers are required!
